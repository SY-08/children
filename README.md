# children — ナレモン（子ども向け AI パートナー・プロトタイプ）

ドット絵のパートナー「ナレモン」と話せる、子ども向けの学習・対話アプリ試作です。
iPhone 風の見た目で、キャラクター4体（ゴロニャン／ヒノコマ／サルミズ／キジミドリ）から選んで使います。

## 特長
- ドット絵キャラ（透過・歩行時に反転）＋草原アニメ、ごはん／なでるのお世話
- 4モード：年少・年中／小1・2／小3・4／小5・6（語彙・言い回しが変わる）
- 安全ガード：自殺・自傷・加害・性的ワードを検知し、固定文で止めて「信頼できる大人へ」誘導
- 音声入力・読み上げ（対応ブラウザのみ）

## 動かし方
1. **Claude アーティファクトに載せる**：`index.html` の中身を Claude のアーティファクトに貼ると、開いた人自身の Claude で AI が動く（バッジが「AI」になる）。
2. **GitHub Pages で配布**：このフォルダを GitHub リポジトリ `children` に置き、Settings → Pages で公開。URL を配れば誰でもブラウザで開ける。ただし GitHub Pages 版は AI 未接続なので、返答は「デモ」。
3. **そのまま確認する**：`index.html` をブラウザで開くと画面と安全ガードを確認できる。ただし AI 未接続なので、返答は「デモ」。

## GitHub Pages 公開手順
1. GitHub で新規リポジトリ `children` を作成
2. このフォルダの中身（`index.html`, `README.md`, `.nojekyll`）をアップロード
3. Settings → Pages → Branch: `main` / フォルダ: `/ (root)` を選んで Save
4. 数分後、`https://<ユーザー名>.github.io/children/` で公開

## 本物のAIについて（重要）
GitHub Pages は「画面を置く場所」で、AI の頭脳は動きません。
無料・キー無しで本物の AI 応答を試す前提では、Claude アーティファクトに載せて、開いた人自身の Claude で動かす方式を基本にします。

Claude の年齢・利用規約に従い、子どもが使う場合は保護者アカウントと保護者の見守りを前提にします。

いずれも「子どもが単独で無制限に使う」設計ではなく、**保護者・先生の見守りを前提**にしてください。
